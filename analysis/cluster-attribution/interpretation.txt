This extends the synthetic native test to the actual deployed path. It does
not establish the synthetic 5-second threshold false pass on live traffic.
All live cases retained the example P99 10-second threshold. Cold/warm image
pull differences and single runs prohibit performance or prevalence claims.
Kubernetes timestamps are second-resolution here; small timing differences
are not a calibrated enforcement-latency estimate.

The fix leaves the separate Namespace output field blank and places the full
identity in netpol. It is a research candidate, not a reviewed upstream API
design. No upstream issue or pull request has been sent.

The current main source also contains the name-only timestamp assignment,
but only pinned v2.5.1 was executed. Do not claim every release is affected.

Novelty remains unresolved. Namespacing keys is conventional engineering.
ATPG indistinguishability and NetCov contribution-aware coverage already
constrain broader attribution claims. The appropriate next gate is a
closest-work and independent-tool comparison, not another large parameter
sweep or an ACM manuscript claiming a new algorithm.
